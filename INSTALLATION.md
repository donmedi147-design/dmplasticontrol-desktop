# 🖥️ Guide Installation DMPlastiControl Desktop

## 📦 Téléchargement Direct

### **WINDOWS 10/11**

1. **Télécharger** : [DMPlastiControl-Setup.exe](https://github.com/donmedi147-design/dmplasticontrol-desktop/releases)
2. **Lancer** le fichier `.exe`
3. **Suivre** l'assistant installation
4. **Créer** un raccourci Bureau (recommandé)
5. **Lancer** en double-cliquant sur le raccourci

**✅ C'est tout ! L'app est prête**

---

### **MAC**

1. **Télécharger** : [DMPlastiControl.dmg](https://github.com/donmedi147-design/dmplasticontrol-desktop/releases)
2. **Double-cliquer** le fichier `.dmg`
3. **Glisser** DMPlastiControl vers "Applications"
4. **Attendre** la copie (30 secondes)
5. **Lancer** depuis Applications

**Note** : MacOS peut afficher "Développeur non identifié". Faire clic-droit > Ouvrir

---

### **LINUX**

1. **Télécharger** : [dmplasticontrol.AppImage](https://github.com/donmedi147-design/dmplasticontrol-desktop/releases)
2. **Rendre exécutable** :
   ```bash
   chmod +x dmplasticontrol.AppImage
   ```
3. **Double-cliquer** pour lancer
4. **Ou en ligne de commande** :
   ```bash
   ./dmplasticontrol.AppImage
   ```

---

## 🚀 Utilisation Quotidienne

### **Lancer l'App**

**Windows** : Double-cliquer raccourci Bureau "DMPlastiControl"  
**Mac** : Cliquer DMPlastiControl dans Applications  
**Linux** : Lancer depuis menu Application  

### **Naviguer**

- **Menu gauche** : Changer de module
- **Haut droit** : Notifications 🔔 + Profil 👤 + Paramètres ⚙️
- **Raccourcis clavier** : Ctrl+D (Dashboard), Ctrl+M (Mix), etc.
